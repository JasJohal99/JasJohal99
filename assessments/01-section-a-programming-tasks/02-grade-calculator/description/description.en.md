> **Marks:** 10
{: .callout-info}

Write a program that:

- asks the user for a score between `0` and `100` (inclusive),
- prints the corresponding grade on its own line:
  - `A` if the score is at least `70`,
  - `B` if the score is between `50` and `69` (inclusive),
  - `C` if the score is between `40` and `49` (inclusive),
  - `U` if the score is below `40`,
- prints `Invalid input` (and nothing else) if the score is outside the range `0`–`100`.

## Example interactions

```console
Enter score: 70
A
```

```console
Enter score: 150
Invalid input
```
