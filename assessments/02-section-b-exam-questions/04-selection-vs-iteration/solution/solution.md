**Selection** is choosing between two or more different paths through the program based on a condition. The program checks the condition and runs different code depending on whether it is `True` or `False`. In Python, selection is written using `if`, `elif`, and `else`.

Example:

```python
age = int(input("Enter your age: "))
if age >= 18:
    print("Adult")
else:
    print("Child")
```

**Iteration** is repeating a block of code more than once. Iteration is used when the same instructions need to run a fixed number of times (`for`) or until some condition stops being true (`while`).

Example:

```python
for i in range(1, 6):
    print(i)
```

This prints the numbers 1, 2, 3, 4, 5 by repeating the same `print` statement five times.

In short: **selection chooses**, **iteration repeats**.
