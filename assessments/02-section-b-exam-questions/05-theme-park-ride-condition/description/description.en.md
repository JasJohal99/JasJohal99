A program checks if a user can enter a theme park ride. To go on the ride, the user:

- must be **over 12 years old**, and
- must be **taller than 1.4 m**.

Write the **Python condition** that checks both of these requirements using a single logical operator.

You can assume the user's age has already been read into a variable `age` (an `int`) and the user's height has been read into a variable `height` (a `float`, in metres).

Show how the condition is used inside an `if`/`else` statement that prints `You can ride.` when both requirements are met, and `You cannot ride.` otherwise.
