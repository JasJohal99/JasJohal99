Write a program that asks the user for a number and then counts down from that number to 0, printing each number on a separate line.

## Input

The program should prompt:

`Enter a number: `

## Output

Print each number from the entered number down to 0, one per line.

## Example

**Input:**
```
5
```

**Output:**
```
5
4
3
2
1
0
```
