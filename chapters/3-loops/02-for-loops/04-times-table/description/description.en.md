Write a program that asks the user for a number and displays the times table for that number, from 1 to 12.

## Input

The program should prompt:

`Enter a number: `

## Output

Display each multiplication from 1 to 12 in the format:

```
i x n = result
```

## Example

**Input:**
```
4
```

**Output:**
```
1 x 4 = 4
2 x 4 = 8
3 x 4 = 12
4 x 4 = 16
5 x 4 = 20
6 x 4 = 24
7 x 4 = 28
8 x 4 = 32
9 x 4 = 36
10 x 4 = 40
11 x 4 = 44
12 x 4 = 48
```
