Write a program that asks the user for a number and displays the square of each number from 1 up to that number.

## Input

The program should prompt:

`Enter a number: `

## Output

For each number from 1 to n, print:

```
The square of i is result
```

## Example

**Input:**
```
4
```

**Output:**
```
The square of 1 is 1
The square of 2 is 4
The square of 3 is 9
The square of 4 is 16
```
