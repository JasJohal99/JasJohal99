Write a program that asks the user for a number and displays an ascending triangle of stars. Each line should contain one more star than the previous line, starting with 1 star.

## Input

The program should prompt:

`Enter a number: `

## Output

An ascending triangle of stars with n rows.

## Example

**Input:**
```
5
```

**Output:**
```
*
**
***
****
*****
```
