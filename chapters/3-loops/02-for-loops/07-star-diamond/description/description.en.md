Write a program that asks the user for a number and displays a diamond shape made of stars. The diamond first grows from 1 star up to n stars, then shrinks back down to 1 star.

For example, with n = 5 the diamond has 9 lines (2n - 1), with line lengths: 1, 2, 3, 4, 5, 4, 3, 2, 1.

## Input

The program should prompt:

`Enter a number: `

## Output

A diamond pattern of stars.

## Example

**Input:**
```
5
```

**Output:**
```
*
**
***
****
*****
****
***
**
*
```
