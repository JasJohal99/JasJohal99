Write a program that asks the user for a positive number and calculates its factorial.

The factorial of a number n (written as n!) is the product of all positive integers from 1 to n. For example, 5! = 1 x 2 x 3 x 4 x 5 = 120.

## Input

The program should prompt:

`Enter a number: `

## Output

```
The factorial of n is result
```

## Example

**Input:**
```
5
```

**Output:**
```
The factorial of 5 is 120
```
