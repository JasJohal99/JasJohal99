Write a program that asks the user for a number and displays the triangle number sequence up to the nth term.

Triangle numbers are formed by adding consecutive positive integers. The sequence starts: 1, 3, 6, 10, 15, 21, ...

- The 1st triangle number is 1 (= 1)
- The 2nd triangle number is 3 (= 1 + 2)
- The 3rd triangle number is 6 (= 1 + 2 + 3)
- The 4th triangle number is 10 (= 1 + 2 + 3 + 4)

## Input

The program should prompt:

`Enter a number: `

## Output

Print each triangle number on a separate line, from the 1st up to the nth.

## Example

**Input:**
```
5
```

**Output:**
```
1
3
6
10
15
```
