Write a program that asks the user for the number of stars per row and the number of rows, then displays a grid of stars.

**Hint:** You can use `print("*", end="")` to print without a newline, and `print()` to move to the next line. Alternatively, you can use string multiplication: `"*" * n` produces a string of `n` stars.

### Example

```
Enter the number of stars per row: 5
Enter the number of rows: 3
*****
*****
*****
```
