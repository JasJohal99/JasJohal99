Write a program that asks the user for a number, then displays all prime numbers from 2 up to and including that number.

A **prime number** is a number greater than 1 that has no divisors other than 1 and itself. Use a nested loop: the outer loop iterates through each candidate number, and the inner loop checks whether it is divisible by any smaller number.

### Example

```
Enter a number: 20
2
3
5
7
11
13
17
19
```
