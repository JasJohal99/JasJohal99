Write a program that keeps asking the user to enter a number. When the user enters `0`, the program should stop and display the total sum of all the numbers entered.

### Input

- A series of integers, one at a time, ending with `0`

### Output

- The total sum of all entered numbers (excluding the `0`)

### Example

```console
Enter a number: 5
Enter a number: 3
Enter a number: 7
Enter a number: 0
The total is 15
```
