Write a program that asks the user to enter a number between 10 and 30 (inclusive). If the number is outside this range, display an error message and ask again. Keep asking until a valid number is entered, then display the number.

### Input/Output

- Prompt: `Enter a number between 10 and 30: `
- Error message: `Invalid! Please enter a number between 10 and 30.`
- On valid input: `You entered X`

### Example

```
Enter a number between 10 and 30: 5
Invalid! Please enter a number between 10 and 30.
Enter a number between 10 and 30: 20
You entered 20
```
