Write a program that keeps asking the user to enter numbers until they enter `0`. When `0` is entered, display the total sum and the average of all the numbers entered. Do not count `0` in the average calculation.

### Input/Output

- Prompt: `Enter a number: `
- Output:
  ```
  The total is X
  The average is Y
  ```

### Example

```
Enter a number: 5
Enter a number: 3
Enter a number: 7
Enter a number: 0
The total is 15
The average is 5.0
```
