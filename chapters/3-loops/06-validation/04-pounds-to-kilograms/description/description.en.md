Write a program that displays a conversion table from pounds to kilograms. Ask the user for the maximum number of pounds to display. Validate that the input is between 10 and 250 (inclusive).

The conversion formula is: `kilograms = round(pounds / 2.2, 2)`

### Input/Output

- Prompt: `Enter the maximum pounds (10-250): `
- Error message: `Invalid! Please enter a value between 10 and 250.`
- Each line of output: `X pound = Y kgs`

### Example

```
Enter the maximum pounds (10-250): 5
Invalid! Please enter a value between 10 and 250.
Enter the maximum pounds (10-250): 12
1 pound = 0.45 kgs
2 pound = 0.91 kgs
3 pound = 1.36 kgs
4 pound = 1.82 kgs
5 pound = 2.27 kgs
6 pound = 2.73 kgs
7 pound = 3.18 kgs
8 pound = 3.64 kgs
9 pound = 4.09 kgs
10 pound = 4.55 kgs
11 pound = 5.0 kgs
12 pound = 5.45 kgs
```
