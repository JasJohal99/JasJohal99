Write a program that asks the user for their surname and first name. Validate each input using `.isalpha()` to ensure only letters are entered. If the input is invalid, display an error and ask again. Once both names are valid, greet the user.

### Input/Output

- Prompts: `Enter your surname: ` and `Enter your first name: `
- Error message: `Invalid! Please enter letters only.`
- Output: `Hello firstname surname, how are you today?`

### Example

```
Enter your surname: Smith123
Invalid! Please enter letters only.
Enter your surname: Smith
Enter your first name: John
Hello John Smith, how are you today?
```
