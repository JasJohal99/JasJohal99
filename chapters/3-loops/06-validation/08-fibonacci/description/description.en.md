Write a program that displays the Fibonacci sequence for a given number of terms. The Fibonacci sequence starts with 0 and 1, and each subsequent number is the sum of the two preceding numbers: 0, 1, 1, 2, 3, 5, 8, 13, ...

Validate that the user enters a number greater than or equal to 2.

### Input/Output

- Prompt: `Enter the number of terms: `
- Error message: `Invalid! Please enter a number greater than or equal to 2.`
- Output: each Fibonacci number on its own line

### Example

```
Enter the number of terms: 1
Invalid! Please enter a number greater than or equal to 2.
Enter the number of terms: 8
0
1
1
2
3
5
8
13
```
