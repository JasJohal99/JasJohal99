A glossary of key terms from Chapter 3.

| Term | Definition |
|------|-----------|
| Repetition | Simply repeating blocks of code, with no specific end-of-loop goal or data source. |
| Iteration | Using repeating code to process a data series for a desired output, e.g. processing a list of names or values. |
| Counter-Controlled Loop | Where a counter is used to control the number of times a block of code is repeated. |
| Fixed Loop | Where code is repeated a fixed number of times, not based on a condition. |
| String | A variable data type which contains a series of characters. |
| Nested Loop | Loops within loops. |
| Conditional Loop | A loop which continues based on a condition. Implemented in Python using the `while` statement. |
| Infinite Loop | A loop which never ends and can only exit using a `break` command. |
| Validation | Checking user-inputted data is in the correct format using various methods, e.g. range, type, length, format, existence, lookup checks. |
| Range Check | Check if a value is within a specific value range, e.g. between numbers 10 and 20, or between letters A to Z. |
