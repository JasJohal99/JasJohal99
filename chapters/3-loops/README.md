# Chapter 3: Loops

Dodona learning activities covering loops in Python — for loops, while loops, nested loops, break, and validation.

## Topics

1. **Iteration and Repetition** — Repetition vs iteration concepts
2. **For Loops** — Counter-controlled loops, `range()`, string iteration
3. **Nested Loops** — Loops within loops, `continue`, list comprehensions
4. **While Loops** — Conditional loops, pre-condition pattern
5. **Infinite Loops and Break** — `while True`, `break`, post-condition pattern
6. **Validation** — Range checks, type checks, input validation
7. **Glossary** — Key terms and definitions

**30 activities** — 9 reading activities and 21 exercises.
